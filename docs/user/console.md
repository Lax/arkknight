# Web 控制台

```bash
arkknight server --open
```

访问 <http://127.0.0.1:7100>（配了 token 则用 `?token=<值>` 首访，前端会存入 localStorage）。

控制台是**单二进制内的静态资源**，经 rust-embed 在编译期嵌入 —— 没有额外服务、没有 CDN 依赖。

## 七页导航

| 页 | 能做什么 |
|---|---|
| **总览** | daemon 状态、调度器开关、活跃会话、最近会话 |
| **会话** | 会话列表、drain（优雅停止） |
| **会话日志** | 手动插队开会话 + WS 实时日志 tail |
| **账号** | 账号 CRUD、启停、补 UID、新建账号 |
| **设备** | 设备列表、连通性测试、**截图** |
| **调度** | 调度策略只读视图 |
| **维护** | 环境体检（doctor） |

## 账号 token 设置

左下角侧栏「API token」。

值须与 `arkknight.toml` 的 `[server].token` **一致**。改配置后需重启 daemon，
再回控制台填入并「保存并刷新」。

- 首次用 `?token=<值>` 访问时，前端自动把 URL 参数落到 localStorage
- 留空 = 不带 `Authorization` 头（要求服务端 `token` 也为空）
- 请求返回 401 时侧栏会红字提示「token 不符或未设置」，并给出服务端返回的
  `hint`（含配置文件路径）

## 账号页

- 列表卡片显示：key、展示名、服务器、UID（无则标「无 UID · 跳过核验」）、已预置设备
- 「补 UID」/「改 UID」按钮内联编辑，纯数字校验，保存即生效
- 「新建账号」表单分两组：
  - **身份标识**：账号 key（本地定位键）/ 展示名 / 服务器 / 切号匹配串 / 游戏 UID / 优先级
  - **调度时间窗**：窗口起止 / 执行器 / maa 任务名
- 每个字段下方有一行说明它干什么用；未填 UID 会弹黄色告警条说明串数据风险
- 时间窗没填完整会禁用执行器下拉，并提示「不限时段参与调度」

## 设备页

- 每台设备一张卡片：后端类型、key、`host=` / `docker=` 地址、备注
- 「测试」按钮：adb 连通性 + 游戏包检测
- 「截图」按钮：抓取当前设备画面（`adb exec-out screencap -p`）
  - 预载成功才显示，失败显示可读错误（设备离线/息屏）而非破图
  - 头部「全部截屏」批量抓取
  - **按需抓取而非轮询** —— 频繁 screencap 会拖慢设备

> 截图是纯 adb 只读操作，不涉及游戏内自动化。

## 会话页与日志页

- **会话**列表可 drain（优雅停止 → 超时后 pid 兜底强杀）
- **会话日志**页可手动开会话（插队语义：priority=100，**不抢占**已 Running 会话），
  并用 WebSocket 实时 tail 日志（`?logs=<session_id>`）

## 调度页

当前**只读**，显示 `[scheduler]` 各字段当前值。策略经工作目录文件管理
（INV-4 单一事实源），表单化编辑属后续批次。

## 维护页（doctor）

点「运行体检」执行完整环境体检，逐项显示 `✓`/`!`/`✗` 与 `↳` 修复提示。
与 CLI 的 `arkknight doctor` 等价。

## WebSocket

控制台用两条 WS：

| 端点 | 用途 |
|---|---|
| `ws://<host>/api/ws?events=1&token=<值>` | 事件流（会话状态机迁移、切号进度） |
| `ws://<host>/api/ws?logs=<session_id>&token=<值>` | 指定会话日志 tail |

## 错误提示怎么读

控制台的错误消息带 `hint` 字段，直接告诉你「去哪里改」：

```json
{
  "error": "账号 ghost 不存在",
  "hint": "账号不存在。已注册：main、alt；新增用 `arkknight account add <key> --server official --account-name '<匹配串>'`"
}
```

常见场景：

| 现象 | 怎么办 |
|---|---|
| 页面能开但数据全空 | token 不对，见左栏提示 |
| 401 且提示「token 已提供但不一致」 | localStorage 里的旧值，清掉后用 `?token=<值>` 重访 |
| 「请求未携带 token」 | 控制台 token 框留空，但服务端 `token` 非空 —— 二者需匹配 |
